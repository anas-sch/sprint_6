# sprint_6

Проект автотестов: Яндекс Самокат

**Описание**

Автоматизированные UI-тесты для сервиса [qa-scooter.praktikum-services.ru](https://qa-scooter.praktikum-services.ru), 
написанные с использованием:

- Python
- Selenium
- pytest
- Allure
- Page Object Model (POM)

Тесты покрывают:
- оформление заказа с двумя вариантами кнопки "Заказать"
- работу FAQ-блока на главной странице
- переходы по логотипам

**Как запустить тесты**

1. Установить зависимости:
2. Запустить все тесты с сохранением результатов для Allure
3. Открыть отчёт Allure

**Список тестов:**

- test_order_page.py — оформление заказа через верхнюю и нижнюю кнопку "Заказать"
- test_main_page.py — тестирование вопросов и ответов
- test_page_redirect.py — переходы по логотипам
